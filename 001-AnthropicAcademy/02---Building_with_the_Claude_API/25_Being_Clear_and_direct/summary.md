# [Being clear and direct](https://anthropic.skilljar.com/claude-with-the-anthropic-api/287744)

## Summary

- すべてに共通して、**promptの一行目は最も大切!!!**
  - 大切なこと
    1. clarity(明確性)
       - シンプルな言葉で、何がほしいか/してほしいか、明確に正確に主張する
    2. directness(直接性)
       - 疑問の提示ではなく、指示を提示する。

## Note/Tips

- 具体的なテクニック
   - "Write", "Create", "Generate", "Identify"のように指示語の動詞で書き始める
   - Claudeにやってほしい作業内容を具体的に書く(～を3つ生成しろ、とか)

## Supplement

- 良い指示は「動詞(何をするか)」「成果物(何を作るか)」「制約(条件)」の3要素で構成される。動詞と成果物だけでなく、満たすべき条件を指示に含めることで曖昧さがさらに減る。
