# [Structure with XML tags](https://anthropic.skilljar.com/claude-with-the-anthropic-api/287741)

## Summary

- promptを構造的にしてClaudeが理解しやすいようにしよう
  - **XML tags**
    - どこからどこまでが、何の属性なのかが端的に明示できるからわかりやすいんだろう。
    - 埋め込んだ情報の境界を示せるため、多量or多種の情報を埋め込む際に有用
      - （少ない情報であっても構造的になるのでClaudeにとってはClearになる）
    - OfficialなXMLタグではなく、あくまでその区間がどんな属性の情報なのかが具体的に示せればいい。

## Note/Tips

- タグ名は具体的・記述的なほど良い（<data> より <sales_records>）
